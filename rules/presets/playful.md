# Playful
**id:** playful · **best for:** kids, learning, games, consumer social, onboarding — anything that should feel fun

**Mood:** bouncy, saturated, friendly. Chunky shapes, bold colour blocking, personality in every corner.

**Type:** display — chunky rounded (Baloo 2, Fredoka, fallback "Trebuchet MS" bold); body — friendly sans (Nunito, "Segoe UI"). Large sizes, display weight 700–800, body 17px.

**Motifs:** 2px dark outlines with chunky bottom shadow, flat colour blocking with purpose, stickers/badges, wiggle/bounce on hover (reduced-motion safe), progress as steps or characters, big tappable buttons.

**Do:** ≤3 accent colours, each with a job; celebratory success states; encouraging copy; ≥48px touch targets.
**Don't:** purple gradients, emoji as the icon set (draw SVG icons/mascot shapes), tiny text, an unranked rainbow.
